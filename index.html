Near Me

Test only. Your location is shown on this screen and never recorded or sent anywhere.

Tap to allow location access.

Only your name is sent, to get a quote. Your location never leaves this phone.

app.js 
// Ask this phone where it is.
const geo = navigator.geolocation;
geo.getCurrentPosition(
  (pos) => {
    const { latitude, longitude } =
      pos.coords;
    // Shown here, never sent.
    status.textContent =
      `${latitude}, ${longitude}`;
  },
  (err) => {
    status.textContent = 'No location.';
  },
  { enableHighAccuracy: true }
);

console.log("What's up Jack!");
